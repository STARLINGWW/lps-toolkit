# LPS Node 命令速查

> 在工程根目录执行：`cd D:\_AAA_CODE_ALL\UWB`
> 串口号用 `python tools\lps_config.py --list` 查，**不要假定是 COM5**

---

## 1. 刷写命令

前置：让板子进刷机模式 —— 按住 **DFU 键(6)** 再插 USB，松手。
（板子在运行时也可让脚本自动做：加 `--enter-dfu --port COMx`）

```powershell
# 最常用：刷固件 + 配角色/编号 + 校验，一条命令
python tools\lps_provision.py --anchor 2          # 基站，编号 2（TDoA Anchor V3）
python tools\lps_provision.py --anchor 0          # 基站，编号 0
python tools\lps_provision.py --tag 20            # 标签/数据出口，编号 20（Sniffer）

# 批量：交互式，每次插一块，自动分配编号
python tools\lps_provision.py --anchors 0-7       # 8 个基站，编号 0~7

# 只刷固件（不改配置）
python tools\lps_flash.py --no-enter              # 板子已在 DFU 模式（手动进的用这个）
python tools\lps_flash.py --port COM17            # 板子在运行，脚本自动发 'u' 进 DFU
python tools\lps_flash.py --all                   # 交互式批量刷固件

# 刷前预检（不写入任何数据）
python tools\lps_flash.py --dry-run

# 速度：默认官方原速约 11 分钟/块（最稳）；下面这个约 1 分钟（有中途失败风险）
python tools\lps_provision.py --anchor 2 --wait-cap 500
```

刷写失败或被中断后的固定动作：**拔掉 USB → 按住 DFU 键(6) → 插 USB → 松手**，再重跑命令。
不会变砖 —— DFU 引导在芯片 ROM 里，擦不掉。

---

## 2. 配置命令

配置写在 EEPROM 里，**改完必须重启才生效**：按 **Reset 键(4)**（右边靠下），或拔插 USB。

```powershell
# 一键配置：固件已刷好，只改角色/编号
python tools\lps_provision.py --anchor 2 --skip-flash --port COM17
python tools\lps_provision.py --tag 20 --skip-flash --port COM17

# 精细配置：逐项改
python tools\lps_config.py --port COM17 --read                 # 先看当前配置
python tools\lps_config.py --port COM17 --id 2                 # 只改编号
python tools\lps_config.py --port COM17 --mode tdoa3           # 只改模式
python tools\lps_config.py --port COM17 --id 2 --mode tdoa3    # 编号 + 模式
python tools\lps_config.py --port COM17 --mode sniffer         # 切成数据出口
python tools\lps_config.py --port COM17 --mode tdoa2           # 兜底：TDoA2 锚点
python tools\lps_config.py --port COM17 --radio 1              # 射频档位（所有节点必须一致）
python tools\lps_config.py --port COM17 --power 3              # 发射功率档位
python tools\lps_config.py --port COM17 --reset                # 恢复默认配置

# 交互式批量分配编号（每次插一块）
python tools\lps_config.py --assign 0-7 --mode tdoa3
```

模式取值：`tdoa3`（TDoA Anchor V3，基站推荐）、`tdoa2`（TDoA Anchor V2，兜底）、
`sniffer`（纯监听，数据出口）、`twr-anchor`、`twr-tag`（官方 TWR 标签，一次只能一个）。

| 角色 | 命令 | 模式 | 编号建议 |
|---|---|---|---|
| 基站 | `--anchor <ID>` | TDoA Anchor V3 | 0–7，各不相同 |
| 标签/数据出口 | `--tag <ID>` | Sniffer | 20（不参与定位） |

## 3. 查看命令

```powershell
# 看硬件
python tools\lps_config.py --list                 # 在线节点 + COM 口
python tools\lps_flash.py --list                  # 顺便看 DFU 设备（0483:df11）

# 看某个节点的当前配置（编号 / 模式 / 比特率 / 前导码 / 坐标）
python tools\lps_config.py --port COM17 --read

# 看 DFU 状态（刷写前确认，bState=2 才正常）
python tools\lps_flash.py --dry-run

# 看射频收发：抓包统计每个基站的收包率（在标签节点上跑）
python tools\lps_capture.py --port COM17 --seconds 30 --summary

# 看功能自检：标签真的监听空口，统计能看到几个基站
python tools\lps_provision.py --tag 20 --skip-flash --port COM17 --test

# 看基站是否在发包（借另一块标签旁听）
python tools\lps_provision.py --anchor 0 --skip-flash --port COM9 --test --with-sniffer COM17

# 看位置：实时解算
python tools\lps_tdoa3_solver.py --port COM17 --anchors tools\anchors_example.yaml
python tools\lps_tdoa3_solver.py --port COM17 --anchors tools\anchors_example.yaml --check
python tools\lps_tdoa3_solver.py --port COM17 --anchors tools\anchors_example.yaml --json

# 看官方解码结果（锚点间实际距离，验证测距链路）
cd clones\lps-node-firmware
python tools\sniffer\sniffer_binary.py COM17 yaml | python tools\sniffer\tdoa3_decoder.py
python tools\sniffer\sniffer_binary.py COM17 yaml | python tools\sniffer\tdoa3_decoder.py | python tools\sniffer\tdoa3_tof.py m
cd ..\..

# 看驱动有没有问题（节点不出 COM 口时）
powershell -ExecutionPolicy Bypass -File .\tools\fix_serial_driver.ps1
```

不看电脑也能判断板子状态：**MODE 灯 常亮=基站，闪烁=Sniffer，熄灭=Tag**；RANGING 红灯闪烁=正在测距。

## 4. 一块板子的完整流程

```
1. 拔掉 USB → 按住 DFU 键(6) → 插 USB → 松手
2. python tools\lps_flash.py --dry-run              # 确认 bState=2
3. python tools\lps_provision.py --anchor 2         # 刷+配+校验，约 11 分钟
4. 按 Reset 键(4) 或拔插 USB                        # 让配置生效
5. python tools\lps_config.py --port COMx --read    # 复核地址/模式/自检
6. 贴编号纸，换下一块
```

## 5. 常见问题对应的命令

| 现象 | 命令 |
|---|---|
| 不知道串口号 | `python tools\lps_config.py --list` |
| 节点不出 COM 口 | `powershell -ExecutionPolicy Bypass -File .\tools\fix_serial_driver.ps1`（管理员加 `-Apply`） |
| 不知道板子是什么模式 | `python tools\lps_config.py --port COMx --read`（或看 MODE 灯） |
| DFU 卡住刷不动 | 按住 DFU 键重新上电，再 `python tools\lps_flash.py --dry-run` |
| 看不到基站 | `python tools\lps_capture.py --port COMx --seconds 30 --summary` |
| 位置解不出来 | `python tools\lps_tdoa3_solver.py --port COMx --anchors tools\anchors_example.yaml --check` |
